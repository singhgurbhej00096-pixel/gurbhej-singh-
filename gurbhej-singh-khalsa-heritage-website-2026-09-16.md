# Gurbhej Singh Khalsa Heritage Website

## Overview
Build a polished, single-page personal heritage website that combines a modern luxury identity with the atmosphere of a Sikh cultural museum. Gurbhej Singh Khalsa’s portrait will remain recognizable and serve as the central visual across the opening and personal-story sections.

## Page structure
- **Navigation:** Home, About, Shastar Heritage, Khalsa History, Craftsmanship, Gallery, Contact; sticky desktop navigation and a compact mobile menu.
- **Opening section:** responsive 16:9 cinematic composition with the portrait, bilingual name, tagline, subheading, restrained heritage patterning, and “Explore Heritage” / “Our Story” links.
- **Personal story:** “The Journey of Gurbhej Singh Khalsa,” using the portrait again in a different crop with respectful editorial copy about preservation, education, craftsmanship, and Khalsa culture.
- **Shastar Heritage:** museum-style educational exhibits covering history, cultural significance, and traditional craftsmanship, with Gurmukhi captions and no weapon-making, modification, or usage instructions.
- **Khalsa History:** a visually rich chronology using parchment surfaces, architectural references, historical art, and subtle gold rules.
- **Craftsmanship:** an editorial section focused on material heritage, artisan skills, preservation, and ornamentation.
- **Gallery:** large cinematic imagery for personal photographs, heritage photography, historical objects, cultural artwork, and craftsmanship, with refined hover treatments and an accessible image viewer.
- **Contact:** a simple enquiry form with name, email, subject, and message fields, plus clear validation and a polished confirmation state. It will be presentation-only unless message delivery is requested later.
- **Footer:** bilingual brand name and “Shastar • Virasat • Khalsa.”

## Visual direction
- Deep black and navy foundations, antique-gold accents, and ivory text.
- Premium serif display type paired with readable body typography and a Gurmukhi-capable family.
- Authentic portrait treatment with cinematic lighting overlays that do not alter the person’s face or create an aggressive mood.
- Restrained Punjabi/Sikh heritage motifs, stone, and parchment textures used as atmosphere rather than decoration overload.
- Smooth entrance and section transitions, gentle image movement, and reduced-motion support.
- Responsive compositions designed for both mobile and wide screens, with strong contrast and readable bilingual text.

## Imagery
- Use the supplied Gurbhej Singh Khalsa portrait wherever personal identity appears.
- Add a cohesive set of supporting museum-style heritage visuals where needed for historical objects, architecture, craftsmanship, and cultural artwork.
- Every image receives descriptive alternative text; historical visuals will be framed as cultural and educational context.
- The portrait file is not currently visible in the project upload area, so implementation will use it as soon as the attachment becomes available; no synthetic replacement of Gurbhej Singh Khalsa’s identity will be made.

## Interaction and quality
- Smooth in-page navigation and clear active states.
- Keyboard-accessible menu, gallery viewer, links, and enquiry form.
- Semantic headings, a single page title, and complete page/social metadata specific to Gurbhej Singh Khalsa.
- Verify visual quality at desktop and mobile sizes, confirm interactions, and check the final preview for errors.

## Technical notes
- Implement as the homepage using the existing React/TanStack structure and Tailwind design tokens.
- Keep all colors and typography in the shared design system rather than scattered page-specific values.
- Use lightweight CSS animation and existing icon utilities; avoid adding unnecessary infrastructure.
- The enquiry form will validate locally and show a confirmation state. Actual email delivery would require a separately requested connected service.
